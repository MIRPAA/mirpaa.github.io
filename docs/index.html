מקום שילדים אוהבים

    הצוות

    הכירו את צוות המרפאה

    רפואה, טיפול והתפתחות — צוות רב־תחומי שמורכב מאנשים טובים, שממש אוהבים ילדים. לחצו על כרטיס כדי להכיר.

    לרופאים ולמטפלים

    הצטרפו למרפאת הילדים

    חדרי טיפול מעוצבים להשכרה לפי ססיות, במרפאת ילדים פעילה, לצד רופאות ילדים, רופאים מומחים ומטפלים. בואו לעבוד במקום שילדים כבר מכירים ואוהבים.
